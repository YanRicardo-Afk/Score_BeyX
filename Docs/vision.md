# Vision

> "Não estamos construindo um placar.
>
> Estamos construindo a melhor ferramenta open source para transmissões de Beyblade X."

---

# Nossa missão

Criar uma plataforma moderna, modular e fácil de usar para gravações, transmissões e campeonatos de Beyblade X.

O projeto deve permitir que qualquer pessoa monte uma transmissão profissional utilizando apenas um computador e um celular.

---

# Nossa visão

Queremos que o Beyblade Overlay Engine seja reconhecido como uma ferramenta completa para organização de partidas de Beyblade X.

O sistema deverá evoluir continuamente, adicionando novos recursos sem comprometer sua simplicidade.

---

# Nossos princípios

## Simples de utilizar

Ligar o servidor.

Escanear um QR Code.

Começar a batalha.

Nada além disso.

---

## Modular

Toda funcionalidade nova deve ser adicionada como um módulo independente.

Nenhum módulo deve quebrar outro.

---

## Escalável

O projeto deve crescer naturalmente.

Adicionar um Bey novo não deve exigir alterações na Engine.

Adicionar uma animação nova não deve exigir alterar o placar.

Adicionar um torneio não deve alterar o sistema de pontuação.

---

## Open Source

O código deve ser limpo.

Documentado.

Organizado.

Fácil de entender.

---

## Visual Profissional

O objetivo nunca será criar efeitos exagerados.

O objetivo é criar uma transmissão bonita, limpa e agradável de assistir.

Cada animação deve melhorar a experiência do espectador.

Nunca distrair.

---

## Mobile First

O Controller deve funcionar perfeitamente em celulares.

Nenhum recurso importante dependerá de mouse ou teclado.

---

## Offline First

O sistema deve funcionar completamente sem internet.

A única exigência é que os dispositivos consigam se comunicar pela rede local.

---

## Performance

O Overlay deve consumir poucos recursos.

As animações devem ser suaves.

A comunicação deve possuir baixa latência.

---

# O que o projeto NÃO é

O projeto não pretende substituir softwares como OBS Studio.

Ele não pretende ser um jogo.

Ele não pretende ser uma rede social.

Ele não pretende depender de serviços online.

Seu objetivo é ser uma Engine especializada para Beyblade X.

---

# Nosso objetivo final

Quando alguém quiser gravar uma batalha de Beyblade X, queremos que a primeira ferramenta lembrada seja o Beyblade Overlay Engine.
